# お礼LINEメーカー

## 何をするツールか
査定後のお客様に送るお礼LINEと、お客様から返信が来たときの返事のたたき台を作るページです。

- **お礼を送る**：「今日の結果（成立／不成立／問い合わせ）」と「来店回数（1回目／2回目／3回目〜）」を選び、その方だけの一言を入れると文面ができあがります。
- **返信が来たとき**：「お礼・あいさつ」なら短いお礼で締め、「相談・質問」ならお電話へ案内する文面ができあがります。LINEのやり取りは1往復までが目安です。
- お礼の文面と「相談・質問」への返事の最後には、店舗名・担当者名（入力したときだけ）・電話番号・受付時間の署名が自動で入ります。
- 文面は自由に手直しでき、「コピーする」でLINEに貼り付けて送信します。

- 公開URL：https://del-works.github.io/thanks-line/
- 検索エンジンに載らないよう `noindex` を設定しています。URLは店舗スタッフにだけ伝えてください。
- お客様名や一言は、その端末のブラウザの中だけで使われます。どこにも送信・保存されません（選んだ店舗だけ、その日のうちはその端末に保存されます）。

## 必要な準備
- インターネットにつながるスマホ・タブレット・PCのブラウザ（Chrome / Safari など）
- アカウントやインストールは不要です

## 起動の仕方
1. 上の公開URLをブラウザで開く（店舗端末ではブックマークかホーム画面に追加しておく）
2. 画面上の「本日の店舗」で、今日いる店舗を選ぶ（その日のうちは自動で残り、日付が変わると選び直しになります。選ぶまではコピーできません）
3. 「お礼を送る」か「返信が来たとき」を選び、ボタンをタップする
4. 査定した本人が送るときは担当者名を入れる（別の人が送るときは空欄のままでOK）
5. 「コピーする」を押し、LINEのトーク画面に貼り付けて送信する
6. 「次のお客様へ」で入力をリセットする（本日の店舗以外が消えます）

### 文面を変えたいとき
`index.html` の中の次の部分を書き換えて、GitHubにプッシュします。1〜2分で公開URLに反映されます。
- `SHOP` / `TEL` / `HOURS`：署名の店名・電話番号・受付時間
- `STORES`：店舗一覧（店舗が増えたら1行追加）
- `OPENING`：来店回数ごとの書き出し（`withStaff` は担当者名あり、`plain` は担当者名なし）
- `RESULT`：結果ごとの文
- `CLOSING`：来店回数ごとの締め
- `REPLY`：返信が来たときの文面
- `CHIPS_COMMON` / `CHIPS_BY_RESULT`：一言の候補

## よくあるエラーと対処
| 症状 | 対処 |
| --- | --- |
| 「コピーする」を押してもコピーされない | 文面が選択された状態になるので、長押しして「コピー」を選ぶ |
| 文面を直したのに古いまま | 1〜2分待ってから、ページを再読み込みする |
| 同じ日なのに店舗の選択が消える | ブラウザのプライベート（シークレット）モードをやめて通常モードで開く |
| 店舗の一覧に自分の店舗がない | 管理者に連絡して `STORES` に追加してもらう |
| 「〇〇が残っています」と出る | 文面の「〇〇」を書き換えてから送る |
| ページが404になる | GitHubのリポジトリ設定 → Pages が有効か、リポジトリ名が `thanks-line` のままか確認する |
